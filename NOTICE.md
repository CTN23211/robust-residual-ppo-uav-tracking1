# Repository scope

This public repository is a curated, simulation-based study of UAV tracking control using classical control, Direct PPO, Residual PPO, and targeted robust Residual PPO.

The repository contains the project's control environments, training/evaluation scripts, frozen result CSVs, final analysis figures/tables, and compact trained policy files needed for the documented experiments.

Generated TensorBoard logs, intermediate checkpoints, backup files, and legacy exploratory plots are intentionally excluded from the public tree.

This repository does not claim originality for Stable-Baselines3 PPO, Gymnasium, NumPy, PyTorch, Matplotlib, or other third-party libraries used as dependencies.
